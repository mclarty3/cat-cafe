# Cat Cafe

Cozy cat-cafe sim (day) + Hollow Knight / Dead Cells-style dream dungeon (night). Godot 4.4, GDScript.
Design lives in `docs/` (an Obsidian vault). Prototype status and next steps: `CAFE_SLICE.md`, `DUNGEON_SLICE.md`.

## Branches
- `main`: **design docs only** (`docs/`). `ryan`: Godot prototype slices (branched from `main`). `darren`: a teammate's branch, don't touch.
- Design-doc changes go to `main`, then merge `main` into `ryan` (don't rebase `ryan`, it's pushed). Use a temporary
  worktree of `main` so the `ryan` working copy isn't disturbed. Slice docs (`*_SLICE.md`, README) stay on `ryan`.
- Godot keeps re-saving `scenes/main.tscn` with its script `uid=` stripped. That stray change is noise: leave it out of commits.
- Design decisions are recorded in the docs with status tags (`[DECIDED]` / `[LEANING]` / `[PROPOSED]` / `[OPEN]` / `[REJECTED]`, dated)
  and a row in `docs/Decision Log.md`. Mark Claude-invented ideas as `[PROPOSED] *(Claude suggestion)*`.

## Skills (`.claude/skills/`)
- `godot-verify`: run a throwaway scripted probe headless (PASS/FAIL) or windowed (screenshots), with a template and a
  helper script (`run_probe.sh`). Use it before reporting changes as working.
- `commit-split`: docs to `main` through a worktree, prototype work to `ryan`, merge `main` into `ryan`, push both.

## Running and verifying (Windows)
- Godot: `"/c/Program Files/Godot_v4.4-stable_mono_win64/Godot_v4.4-stable_mono_win64_console.exe"` (Mono build, but GDScript only).
- Re-import after adding assets: `godot --headless --path . --import` (ignore the "progress dialog" / "Parameter t is null" errors).
- Smoke-test: `godot --headless --path . res://scenes/cafe/cafe.tscn --quit-after 90` and grep for `SCRIPT ERROR|Parse Error`.
- Scripted tests: write a throwaway scene + script in `_probe/` that instantiates `scenes/cafe/cafe.tscn`, drives it
  (input via `Input.parse_input_event(InputEventAction)`, or call methods directly), prints PASS/FAIL, then delete `_probe/`.
- Screenshots: run the probe scene **without** `--headless` (opens a window) and save
  `get_viewport().get_texture().get_image()` after `await RenderingServer.frame_post_draw`. Check visual changes this way.
- In-game: F9 during cafe service skips to closing time (debug builds).

## Gotchas
- Shell heredocs with lots of quotes sometimes fail to parse in this environment: write Python/GDScript to a file instead.
- Python on Windows defaults to cp1252: use `PYTHONUTF8=1` / `encoding="utf-8"` (the docs contain non-ASCII).
- `.tscn` `Transform3D(...)` text lists the basis **row by row** (getting this transposed flips rotations).
- `scenes/cafe/cafe.tscn` is generated by `tools/gen_cafe_layout.py`, which overwrites it. Edit the generator, or retire it.
- Navigation needs `navigation/3d/default_cell_size` = the NavigationMesh `cell_size` (both 0.1); the navmesh is baked at
  runtime from StaticBodies under the `nav_source` group.
- Children's `_ready` runs before the parent's: nodes needing the cafe use the `cafe` group (joined in `_enter_tree`).

## Cafe code map (`scripts/cafe/`)
- `cafe.gd`: day flow (morning prep → service → results), queue, tickets, pass, seating, cats, camera focus.
  Tuning is exported on the `Cafe` node. `cafe_data.gd`: content tables (menu, prep, cats, personalities, regulars).
- Stations extend `Station` → `Interactable` (`get_prompt()` / `interact()`). The register's computer runs CafeOS
  (`ui/computer_panel.gd`) before opening.
- `Prop3D` places any model with an auto collider; `AnimatedModel` plays Kenney animations; `OverlayAnchor` pins 2D
  bubbles over 3D nodes; `CafeCamera` is the perspective follow camera.
- Audio: `Audio` autoload; every sound is named in its `SOUNDS` table (Music and SFX buses, with a low-pass on SFX).
- Cats are spawned from `CafeData.CATS`; the full cat schema and generation plan is in `docs/Cats.md`.
